# 3.3.0 更新说明

- 电影页类型、年份平铺筛选，更多/收起与近期热度排序。热度来自外部推荐缓存，不代表本站播放量。
- 直播采用频道卡片墙，按订阅分组，同名备用线路合并选择。
- 设置页支持刷新已配置源目录，保留刷新失败前的缓存。
- 新增 scripts/maintenance.mjs：后台健康检查、Windows 缺失服务启动尝试、直播订阅缓存更新、影视目录更新。记录 runtime/maintenance.json，不记录密码或源地址。
- 保留原生播放内核和 NAS 独立控制栏。

## 每日维护（Windows）

先完成 README 安装及配置，手动执行 `node scripts/maintenance.mjs` 验证。
在 Windows 任务计划程序创建当前用户任务：每日 03:00 与用户登录时触发；操作填写 node.exe 完整路径，参数为 maintenance.mjs 的完整路径（含空格请加引号），起始位置为仓库根目录。勾选“错过计划开始时间后，尽快启动任务”，禁止并行实例。任务需要用户登录及 Node 可用；不负责开机或唤醒。时间采用 Windows 本地时区。

完全停止的后台可尝试自动启动；部分端口已被占用或服务挂起时保守报错，不杀进程。日志失败不等于自动恢复完成。直播刷新只验证订阅读取，不检测每条流的实际播放，也不自动发现新源。私有部署中的 Codex 定时任务不随开源仓库分发。

## 安装包与范围

Release APK 使用独立的公开发行签名，与家庭私有安装签名不同；私有安装不要直接覆盖或卸载，继续使用私有构建升级。自行构建也应长期保留自己的签名密钥。

Android 最低 5.0，主要验证环境 Android 8.0。路由器/光猫部署未实现。后台仍需常开电脑。仓库不提供具体点播源或直播订阅链接，参见 SOURCES.md。
