# 安装与部署

## 依赖环境

| 项目 | 要求 |
|---|---|
| 电脑 | 推荐 Windows 10/11、PowerShell |
| Node.js | 22.12+ LTS，包含 npm，支持 --env-file |
| 电视 | Android 5.0+；Android 8.0 为开发验证环境 |
| 网络 | 电脑、电视在同一可信局域网 |
| APK 构建 | JDK 8、Android SDK platforms;android-30、build-tools;30.0.3 |
| 可选 | ADB；也可通过 U 盘安装 |

Node、JDK、SDK 和 npm 依赖需另行安装，不随源码包分发。其他电脑系统可手动运行 Node 服务，但 Windows 以外尚未全面验证。

## 1. 初始化后台

克隆仓库或解压源码，进入项目根目录：

```powershell
git clone https://github.com/lcacvc210-alt/VelaNestTV.git
cd VelaNestTV
```

然后在 PowerShell 中执行：

```powershell
cd backend
npm ci
Copy-Item .env.example .env.local
notepad .env.local
npm run build
cd ../companion
npm ci
Copy-Item .env.example .env
notepad .env
cd ..
```

两处 PASSWORD 必须一致。自行填写有权访问的点播 API 和直播订阅，默认不附带第三方片源列表。NAS_ROOT 填写电影文件夹绝对路径；不填时使用项目 media/。

## 2. 启动服务

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/start.ps1
Invoke-RestMethod http://localhost:8080/api/status
Invoke-RestMethod http://localhost:8090/health
```

日志位于 runtime/。不要重复启动；脚本不是开机自启服务。电脑需保持开机、不休眠。停止命令：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/stop.ps1
```

也可手动运行：终端一进入 backend，执行 `npm run start -- -H 0.0.0.0`；终端二进入 companion，执行 `node --env-file=.env server.mjs`。不要与启动脚本同时使用。

## 3. 构建 APK

安装指定 SDK 包，以实际路径替换下面示例：

```powershell
$env:JAVA_HOME='C:/Java/jdk8'
$env:ANDROID_SDK_ROOT='C:/Android/Sdk'
./android/build.ps1
```

输出为 android/dist/VelaNestTV-3.1.1.apk。首次构建会在 android/private/ 生成本地签名密钥和密码文件，请私下备份，切勿提交。

**自编译的新签名不能默认覆盖维护者签名的 APK。** 同签名升级直接覆盖安装，不要先卸载。更换签名往往需卸载，卸载会丢失配置与记录。

## 4. 电视安装

将 APK 放入 U 盘，通过电视文件管理器打开，按提示允许安装来源。或在自己的电视开启网络调试、接受授权后，使用实际 IP 和调试端口：

```powershell
adb connect YOUR_TV_IP:5555
adb -s YOUR_TV_IP:5555 install -r ./android/dist/VelaNestTV-3.1.1.apk
```

应用内填写 `http://电脑局域网IP:8080` 与 PASSWORD。电视上的 localhost 指电视本身，不能用于连接电脑。

## 变量说明

| 文件 | 变量 | 必需／默认 | 作用 |
|---|---|---|---|
| backend/.env.local | PASSWORD | 必填 | 登录密码 |
| backend/.env.local | DEFAULT_SOURCES | [] | 点播源单行 JSON 数组 |
| backend/.env.local | DEFAULT_LIVE_SOURCES | [] | M3U 订阅单行 JSON 数组 |
| backend/.env.local | LIVE_ALLOW_PRIVATE | 0 | 仅访问可信私网直播地址时设为 1 |
| backend/.env.local | REQUEST_TIMEOUT | 8000 毫秒 | 上游请求超时 |
| backend/.env.local | MAX_RETRIES | 1 | 上游重试次数 |
| backend/.env.local | PROXY_SECRET | 从 PASSWORD 派生 | 可选签名密钥 |
| backend/.env.local | COOKIE_SECURE | 自动 | 可选 Cookie Secure 策略 |
| backend/.env.local | 60S_API_BASE | 上游默认 | 可选推荐 API 地址 |
| backend/.env.local | DEBUG | false | 调试输出 |
| companion/.env | PASSWORD | 必填 | 与后台密码一致 |
| companion/.env | CORE_URL | http://127.0.0.1:8080 | 伴随服务访问后台的地址 |
| companion/.env | NAS_ROOT | 项目 media/ | 只读共享的电影文件夹 |

构建变量 JAVA_HOME/JDK_HOME 指向 JDK 8 根目录；ANDROID_SDK_ROOT/ANDROID_HOME 指向 SDK 根目录。前一项设置优先。

点播源格式示例，example.invalid 为占位符，不能播放：

```dotenv
DEFAULT_SOURCES=[{"name":"My API","url":"https://example.invalid/api.php/provide/vod","isAdult":false}]
DEFAULT_LIVE_SOURCES=[{"name":"My Live","url":"https://example.invalid/channels.m3u"}]
```

API 须兼容 provide/vod 的目录、搜索、详情格式，不能填写普通视频网站主页。JSON 保持单行。带空格的路径可写 `NAS_ROOT="F:/My Movies"`。修改后重启服务。

TCP 8080 用于后台，TCP 8090 用于伴随服务，UDP 45831 用于发现。8090 和 45831 在电视客户端固定；服务虽支持测试端口覆盖，正式部署仍应使用默认值。

## 排障与限制

- 无法连接：检查服务、电脑 IP、私有网络防火墙、休眠及访客 Wi-Fi 隔离。
- 密码错误：确认后台、伴随服务、电视三处一致。
- 搜索为空：检查配置的源及伴随服务日志，空数组表示未配置源。
- 卡顿：尝试换源并检查网络与编码兼容性，不保证所有 4K 都流畅。
- NAS 文件缺失：检查 NAS_ROOT、读取权限和视频扩展名。只共享该文件夹。
- 字幕：仅支持系统可识别的内嵌轨道，外挂字幕尚未接入。
- 当前针对家庭可信局域网，勿直接映射端口到公网。NAS 签名链接最长约 12 小时，勿公开。

companion/data/ 保存缓存、后台身份和 NAS 密钥，升级时保留、不要上传。完整英文说明见 INSTALL.md 和 CONFIGURATION.md。
