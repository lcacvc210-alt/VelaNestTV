# 电影筛选和更新来源（3.2.0）

电影页顶部可组合选择类型、年份和排序，并可一键重置。筛选在分页之前执行，翻页保持条件。类型和年份依赖来源提供的元数据；缺少字段的影片不会被臆测归入某个类型或年份。上映年份使用数据中的年份；更早年份指当前年之前第六年及更早。

排序有最新更新、上映年份、近期热榜。近期热榜来自缓存的外部“热门电影”片单顺序，显示原始名次和更新时间，**不是本应用播放次数，也不代表全网实时热度**。外部片单不可用时提示不可用，不生成虚构排名。更新失败会保留上一份可用热门片单。

设置中的“更新源”请求电脑伴随服务重新读取后台 defaultSources，检查已配置来源目录，并刷新片单、类型、年份和热门片单。显示进度与各来源目录状态；关闭弹窗后后台继续。正在更新时重复点击不会启动第二个更新任务。成功后电视同步来源配置；重进电影页可刷新结果。

这不是从互联网自动寻找或导入新来源。更改后台环境变量中的来源，需要先重启后台使变量生效，再执行更新。目录可用不保证每部影片都能播放或持续流畅。

接口：登录后 POST /tv/sources/refresh 启动，GET 同一路径查看状态。电影目录 GET /tv/catalog?category=movie 支持 genre、year、sort 和 page；sort 为 updated/year/hot，year 为四位年份或 older，空值不筛选。

相关测试：`node --test scripts/catalog.test.mjs scripts/smoke.test.mjs`。
